# RoughLibrarian

RoughLibrarian enables real-time entity disambiguation and data normalization across diverse datasets, indexing knowledge for scalable server systems.

RoughLibrarian is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/RoughLibrarian.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
